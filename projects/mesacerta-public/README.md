# Mesa Certa

> Portfólio público de um projeto com código e dados operacionais privados.

**Mesa Certa** é um sistema criado para organizar as rodadas de negócio do **Get Connected Sorocaba 2026**.

O sistema foi utilizado na operação real do evento.

## Problema

Distribuir participantes entre diferentes mesas em várias rodadas parece simples, mas envolve restrições importantes:

- uma pessoa não deve repetir a mesma mesa;
- patrocinadores/anfitriões precisam permanecer em posições fixas;
- o sistema precisa distribuir os participantes de forma equilibrada;
- cada participante precisa receber um roteiro individual claro.

Fazer isso manualmente em planilhas se torna difícil de validar e sujeito a erros.

## Solução

O Mesa Certa automatiza a distribuição e gera:

- composição das mesas por rodada;
- validação de repetições;
- anfitriões fixos;
- roteiro individual por participante;
- visão operacional pronta para uso no evento.

## Aplicação prática

O sistema foi desenvolvido especificamente para uma operação real de networking empresarial e publicado para uso via web.
