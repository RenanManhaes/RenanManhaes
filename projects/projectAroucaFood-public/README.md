# AroucaFood

> Portfólio público de um projeto com código-fonte privado.

**AroucaFood** é uma aplicação de e-commerce mobile/web desenvolvida para uma operação real de açougue e conveniência.

O projeto reúne experiência de compra para o cliente e ferramentas administrativas para gestão de produtos, estoque e pedidos.

## Problema

A operação precisava centralizar:

- catálogo;
- pedidos;
- estoque;
- produtos;
- categorias;
- autenticação;
- administração;
- acompanhamento de itens críticos.

## Solução

A aplicação possui dois fluxos principais.

### Cliente

- catálogo;
- busca;
- filtros;
- carrinho;
- checkout;
- cadastro e login;
- perfil;
- acompanhamento de pedido.

### Administração

- CRUD de produtos;
- gestão de categorias;
- controle de estoque;
- gestão de pedidos;
- controle de acesso administrativo;
- indicadores de estoque e validade.

## Arquitetura

Aplicação construída com **React Native + TypeScript**, usando **Firebase** para autenticação, banco de dados, storage e funções de backend.

O projeto também inclui regras de segurança e rotinas administrativas.

## Stack

- React Native
- TypeScript
- Expo
- Firebase Auth
- Firestore
- Firebase Storage
- Firebase Functions
- ESLint
- SonarCloud

## Engenharia e conformidade

O projeto possui:

- regras de acesso do Firestore;
- regras de Storage;
- scripts administrativos;
- pipeline de qualidade;
- política de privacidade;
- termos de uso;
- processo de retenção e anonimização de dados.

## Código-fonte

O código principal permanece privado porque o projeto foi desenvolvido para uma operação comercial real e contém integrações e configurações internas.

Este case apresenta apenas informações técnicas e de produto que podem ser divulgadas com segurança.
